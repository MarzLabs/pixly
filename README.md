# Pixly

Chrome extension (Manifest V3) for visual layout inspection and comparison against Figma designs. Built with Vite, TypeScript, `@crxjs/vite-plugin`, and Shadow DOM to isolate every injected UI element from the host page.

## Features

### Stage 1 — Inspection & measurement

- Element inspector with dimensions and distances to the parent.
- Paint backgrounds with `Shift+Click` and outlines with `Ctrl+Shift+B` using the selected palette color.
- Typography inspector (font-family, size, line-height, letter-spacing, weight, color) with copyable values.
- Background color picker in hex and rgb formats.
- Full CSS spec capture for any element in a floating panel with "Copy all".
- Global outlines to visualize every block.
- Inspect spacing (padding in green, margin in orange).
- Configurable grid overlay (columns, gutter, max width, color, opacity).
- Draggable rulers & guides.
- Distance meter between two elements (horizontal, vertical, diagonal).
- Floating magnifier with adjustable zoom.
- Customizable color palette (up to 20 colors).
- Configurable keyboard shortcuts with conflict detection.
- Automatic cleanup when the page reloads.

### Stage 2 — Compare with Figma

- Load an overlay image (PNG, JPG, WEBP, SVG; up to 20 MB).
- Adjustable opacity (0–100%).
- Drag to align with the implementation.
- Blend modes (normal, multiply, screen, overlay, difference, exclusion).
- Page snapshot via `chrome.tabs.captureVisibleTab` and side-by-side view with synchronized scroll.
- Temporary persistence: switching tabs and returning keeps the overlay state.

## Requirements

- Node.js 20+
- npm 10+

## Install dependencies

```bash
npm install
```

## Development

```bash
npm run dev
```

Vite keeps an incremental build under `dist/`. Load the unpacked extension in Chrome (see next section).

## Production build

```bash
npm run build
```

Generates the packaged extension under `dist/`.

## Load the extension in Chrome (unsigned)

1. Run `npm run build`.
2. Open `chrome://extensions/`.
3. Enable "Developer mode" (top-right corner).
4. Click "Load unpacked".
5. Select the `dist/` folder generated by the build.

The Pixly icon will appear in the toolbar. Click it to open the popup.

## Default shortcuts

- `Alt+I` — Element inspector
- `Alt+T` — Typography inspector
- `Alt+G` — Grid overlay
- `Alt+O` — Show/hide image overlay
- `Esc` — Exit any active mode
- `Shift+Click` — Paint element background
- `Ctrl+Shift+B` — Apply outline to element

You can customize these from the "Settings" tab in the popup.

## Structure

```
src/
├── background/           # Service worker (Manifest V3)
├── content/              # Content script and injected tools
│   ├── overlay/          # Image overlay and snapshot (Stage 2)
│   ├── tools/            # Individual tools (Stage 1)
│   └── styles/           # CSS isolated inside the Shadow DOM
├── popup/                # Popup UI
├── shared/               # Shared constants, types, and utilities
└── manifest.config.ts    # Manifest generated by @crxjs/vite-plugin
```

## Privacy

- No overlay image is uploaded to a server: everything stays in the local browser session (`chrome.storage.local` and content script memory).
- Snapshots are generated locally via `chrome.tabs.captureVisibleTab` and shown only in the active tab.
